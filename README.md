# Lumo

Appli de productivité gamifiée : tes tâches font grandir une créature de lumière.
Le cahier des charges complet est dans [BRIEF.md](BRIEF.md).

## Lancer en local

```bash
npm install
npm run dev
npm test   # règles du jeu et sauvegarde
```
